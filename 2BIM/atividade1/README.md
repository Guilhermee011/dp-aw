# Estrutura Básica de Site

##  Descrição
Atividade para criar a estrutura básica de um site em HTML, utilizando as tags **`<header>`**, **`<main>`** e **`<footer>`**.

##  Arquivo
- **estrutura-basica.html** — contém o código do site com cabeçalho, corpo e rodapé.

##  Estrutura
- **Header:** nome do site.  
- **Main:** texto principal do conteúdo.  
- **Footer:** rodapé com direitos autorais.

##  Objetivo
Praticar o uso de elementos semânticos do HTML para organizar a estrutura de uma página web.
