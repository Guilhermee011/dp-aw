# Minha Tabela

##  Descrição
Atividade para criar uma tabela em HTML com 3 colunas e 5 linhas.

##  Arquivo
- **minha-tabela.html** — contém o código da tabela.

##  Estrutura
- **`<th>`** — usado para os cabeçalhos das colunas.  
- **`<td>`** — usado para os dados das células.  

##  Objetivo
Praticar o uso correto das tags de tabela (**`<table>`**, **`<tr>`**, **`<th>`**, **`<td>`**) no HTML.
